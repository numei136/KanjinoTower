# 漢字の塔

漢字がテーマの、デッキ構築型ローグライクです。漢字の敵と戦い、カードを集めて、塔を登ります。

## 遊ぶ
https://numei136.github.io/KanjinoTower/
## 遊び方
- 毎ターン、エナジー3と手札5枚で戦います。敵の次の行動が予告されます。
- 勝つと、カードやレリックをもらえます。分岐するマップを進み、ボスを倒します。
- 6人のキャラから選べます(剣士・守護者・薬師・術師・召喚師・合成師)。
- 詳しい説明は、ゲーム内のチュートリアルにあります。

## 注意
- 進行状況、図鑑、実績、設定は、ブラウザの中に保存されます。ブラウザのデータを消すと、消えます。
- スマホの表示や音は、まだ十分に確認できていません。
